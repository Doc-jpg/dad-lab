# Installing and linking devices

## First device (two minutes)
1. Safari (iPhone or iPad), go to https://doc-jpg.github.io/dad-lab/
2. Share, Add to Home Screen, Add. Open it from the home screen, online.
3. "Is this the first device?" → **Yes, set it up here**. Name, band days a week to aim for, your band names, a look. Done.
4. The next screen shows the device link. **Send myself the link** (Messages, AirDrop, Mail to yourself) and it is there for the next device. The 20-character code is shown too; both live under Settings, Linked devices, from then on.
5. Skip or take the tour. Check in.

## Other devices (one minute each)
Install the same address the same way, then either open the link you sent yourself (it lands on "Device link", tap Link this device) or open the app, choose **No, link it to the one I already set up**, and type the code. Everything arrives on its own; from then on the devices keep each other in step whenever one opens the app with a signal, after every change, and every two minutes while open. iPhone and iPad web apps do not run in the background, so "automatic" means on the next open.

## Laptop
Same address in Chrome or Edge works as a tab; Chrome's "Install app" puts it in the dock. Link it the same way.

## Backups
Settings, Back up everything, share the ZIP to Files or iCloud Drive every few weeks. Linked devices are a copy, not a backup against a mistake made on both. Restore: Settings, Restore or merge a backup file; Merge is safe, Replace wipes the device first (the device link stays).

## If something goes wrong
- "Last try failed" under Linked devices: usually no signal; it retries on its own. If it says the project is paused, the Supabase dashboard (project athletic-lab, shared with Eli's app) restores it with one click.
- "Running in a browser tab": not installed on the home screen; do step 2.
- Erase this device (Settings) wipes this device only; link again and it all comes back from the cloud copy.
